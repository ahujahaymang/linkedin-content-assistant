📝 LinkedIn Post Extractor

Extract all your LinkedIn posts for content analysis

📋 Instructions:
  1. For Posts: Go to https://www.linkedin.com/in/YOUR-USERNAME/recent-activity/all/
  2. Open browser console (F12 or Cmd+Option+J)
  3. Click "Copy Extraction Script" below, paste in console, press Enter
  4. Wait for extraction to complete and download the JSON file
  5. For Articles: Go to https://www.linkedin.com/in/YOUR-USERNAME/recent-activity/articles/
  6. Run the script again (same steps)
  7. You'll get a second JSON file with articles
  8. Import both files separately
⚠️ Important: LinkedIn separates posts and articles into different pages. Run the script on BOTH pages to get complete history:
  • /recent-activity/all/ - Regular posts and reposts
  • /recent-activity/articles/ - Newsletter articles
